# Separate documents

Use this folder for documents that span multiple parts of the repository.
Setup instructions and component guides live beside the code they describe,
so they stay easy to find when that code changes.

If you're getting started, open the [repository guide](../README.md).
For the runnable demo, follow the [infrastructure setup](../code/infrastructure/README.md).
For the application/platform split, read [the code overview](../code/README.md).

When adding documentation, put app instructions beside the app and chart
instructions beside the chart. Put a document here when it needs its own home,
then link to it from the relevant README.
